Game not functional on mobile and there are no plans to add this.

Controls;

W, Space, Upper arrow key- Jump
A, left arrow key- Left
D, right arrow key- Right

Shift- sprint

Esc- pause

Left mouse click- when rolling pin is obtained, click enemies to deal damage provided the enemy is within the ring that appears when a left click is performed.
